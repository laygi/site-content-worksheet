# 網站內容填寫表

給客戶在網站線框（wireframe）裡直接填文案的一頁式工具。填完按「交件」下載一份
整理好的 Word 檔，傳給設計師。

**開啟網址：** https://laygi.github.io/site-content-worksheet/

## 怎麼用

1. 把網址傳給客戶，他點開就能填，不用註冊、不用安裝任何東西
2. 左側最上面是「網站通用設定」（品牌名、LOGO、導覽列中文命名…），下面是八個頁面
3. 灰底框直接打字，灰底斜線方塊可以放圖，紅框是要請他決定的事
4. 填完按右上角「交件」→ 下載 `.doc`，傳回來

共 115 題。內容會自動記在**客戶自己的瀏覽器**裡（不是雲端），關掉再開還在；
但換電腦、換瀏覽器、清資料就沒了 —— 所以工具裡提醒他要換電腦前先按「存檔」下載 `.json`。

## 按鈕

| 按鈕 | 做什麼 |
|---|---|
| 讀取存檔 | 載入之前下載的 `.json`，接著填 |
| 存檔 | 下載 `.json`（填到一半的進度） |
| 列印／PDF | 一次印出全部頁面，或存成 PDF |
| 這頁存成圖 | 目前這一頁存成 PNG |
| 交件 | 下載整理好的 Word `.doc` |

## 改內容

題目都寫在 `index.html` 最底下那段 `<script>` 裡的 `PAGES` 物件，用
`T()`（文字欄）、`IMG()`（圖片格）、`ASK()`（要客戶決定的事）、`SEC()`（區塊）組成。
改完直接 commit，GitHub Pages 會自己更新。

## 這是單一檔案

整份工具就是一個 `index.html`，沒有 build、沒有相依套件。
唯一的外部資源是 Google Fonts（Noto Sans TC）和 html2canvas（存成圖用，沒網路時只是那顆按鈕失效）。
